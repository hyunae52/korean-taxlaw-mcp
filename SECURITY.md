# Security policy

## Supported scope

Security fixes target the current Hyunae downstream release and `main`. The
upstream project has its own maintainership and disclosure process.

## Reporting

Do not publish credentials, personal data, taxpayer facts, or exploit details
in an issue. Open an issue titled `Security contact request` without technical
details so a maintainer can arrange a private channel. If GitHub private
vulnerability reporting is enabled, use `Security` -> `Report a vulnerability`.

Include the affected downstream version or commit, impact, and minimal safe
reproduction. Do not perform load or availability attacks against the original
tax-data sites or `law.taxlab.kr`.

This limited beta has no guaranteed response time or uptime commitment.
